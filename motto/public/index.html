Buy a research-source pack

Purchase three citation records about your topic. Motto fetches live Crossref metadata, validates the deliverable and signs the result. The configured ceiling is $1; incomplete results return the full authorization.

npx --yes --package @solana/pay pay --sandbox curl -sS -X POST http://127.0.0.1:8787/v1/rent/research -H 'Content-Type: application/json' -d '{"query":"retrieval augmented generation"}'

Live research data · test USDC. Crossref metadata is public; Motto packages and checks it. No full text or semantic quality guarantee.

Let Claude make the purchase

On your partner’s computer with Claude Code access, run from the repository root:

node demo/run-agent.mjs

The agent reads terms, purchases the pack, and reports the actual titles and DOI links.
